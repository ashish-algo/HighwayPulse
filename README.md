HighwayPulse 🚧

Highway Defect Prioritization & Maintenance Planning Dashboard

HighwayPulse is a frontend dashboard for managing highway defect reports, prioritizing maintenance tasks, and visualizing road-related data.

Features

- Interactive dashboard with key statistics and charts.
- Defect reporting, search, filtering, and status tracking.
- Interactive highway map with defect markers.
- Priority scoring based on severity, traffic exposure, safety risk, and time unresolved.
- Maintenance planning and analytics.
- Local data persistence using LocalStorage.
- Responsive interface for desktop and mobile.

Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js, Leaflet.js, and OpenStreetMap (where implemented)

Disclaimer

This is an independent educational project using fictional demonstration data. It is not an official NHAI application, and its priority score is an illustrative model, not an official engineering standard.
