# HighwayPulse Image Assets

This directory is reserved for image assets, road cross-section diagrams, or defect photo attachments.

## Conventions
- **Vector Icons & Logos:** HighwayPulse renders all UI icons and brand marks using lightweight inline SVGs directly in HTML and CSS. This guarantees high DPI crispness on retina screens without external image requests.
- **Defect Field Attachments:** In future iterations featuring image upload capability, compressed JPEG/WebP photos can be stored locally or referenced via relative paths in this folder.
- **Licensing:** Any added photographic assets must use permissive licenses (such as Creative Commons CC0 or Public Domain) without proprietary copyright restrictions.
